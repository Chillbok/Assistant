# 문서

| 문서 | 내용 |
|---|---|
| `roadmap.md` | 전체 개발 순서, 보류 목록, 진행 기록 |
| `plans/phase1a.md` | 1a 위험 확인 게이트 계획 (완료, 이력) |
| `plans/phase1b.md` | 1b 전화 위임 계획 (확정) |

## 운영 규칙

- 로드맵의 원본은 Obsidian 볼트 노트다. 단계를 마칠 때 이 디렉터리로 복사한다
- 구현 중 세부 계획과 검증 기록은 `plans/phase*.md`에만 쓴다
- 문서에 시크릿 값을 쓰지 않는다. 환경변수 이름과 파일 경로까지만 적는다
- 새 단계를 시작하면 `plans/phase<번호>.md`를 만들고 검증 결과를 같은 파일에 남긴다
